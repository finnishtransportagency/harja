# Dashboard-proton havainnot

Tämä tiedosto on asiakaskierrosten havaintoloki. Kirjaa tähän, mitä käyttäjä teki, sanoi tai jätti tekemättä proton äärellä. Käyttäjätarpeet säilyvät tiedostossa `paatokset.md`, eikä raakapalautetta siirretä sinne ilman erillistä päätöstä.

## Kirjaustapa

- Lisää kirjaus asiakaskierroksen jälkeen.
- Erottele havaittu toiminta, asiakkaan sanat ja oma tulkinta toisistaan.
- Kirjaa asiakkaan sanat sanatarkasti vain, jos ne on oikeasti sanottu. Älä keksi lainauksia.
- Merkitse seuraava kysymys, jos havainto ei vielä ratkaise asiaa.
- Jos havainto muuttaa pysyvää käyttäjätarvetta tai avointa kysymystä, päivitä `paatokset.md` erikseen.
